# 国家智慧教育平台教材一键下载 Chrome 插件

一款轻量、实用的 Chrome 扩展（基于 Manifest V3），专为**国家中小学智慧教育平台**（`basic.smartedu.cn`）设计。在浏览教材详情页时，自动在页面右下角显示一个“下载本课本 PDF”悬浮按钮，支持一键将原版高清教材 PDF 保存到本地。

---

## 核心特性

- **双模自适应提取**：
  - **内存极速导出**：对于同源 PDF.js 阅读器（如人教版语文等），直接从前端内存中提取已加载的数据，秒级导出，不占用额外网络流量。
  - **动态鉴权下载**：对于跨域阅读器（如英语等），自动提取包含时效签名的鉴权请求头（`x-nd-auth`）并抓取完整高清原件。
- **SPA 单页应用自适应**：支持实时监听路由与 DOM 变化，切换不同年级或学科教材时自动更新。
- **现代化原生视觉**：采用现代科技蓝胶囊设计与动画反馈（准备 -> 导出 -> 成功提示），不干扰正常阅读。

---

## 安装使用教程

1. 打开 Chrome / Edge / Brave 或任何 Chromium 内核浏览器。
2. 在地址栏输入并访问：
   ```
   chrome://extensions/
   ```
3. 在页面右上角开启 **「开发者模式」（Developer mode）**。
4. 点击左上角的 **「加载已解压的扩展程序」（Load unpacked）**。
5. 选择此插件所在文件夹：
   ```
   /path-to-the-git-repo/smartedu-downloader-extension
   ```
6. 安装完成后，打开任意智慧教育平台教材页面（例如五年级英语或语文），稍等片刻，即可在页面右下角看到蓝色的 **「下载本课本 PDF」** 悬浮按钮，点击即可直接下载！
